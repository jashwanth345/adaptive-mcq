# Combined Phase 15 / Phase 16 plan

Authorized together on 12 October 2026. Phase 15 delivers start/resume, immutable item/option permutations, server deadlines, saved choices/flags, revision checks, idempotent server grading and teacher-controlled result release. Code expiry/removal/closure blocks new starts; an admitted running attempt retains its snapshot and may finish until its deadline. Expiry finalizes saved responses on the next server interaction, without accepting late answers. Completed results preserve original-key scoring; quarantined items are labelled under review and excluded from learner evidence.

Private practice uses a student's own latest, genuinely verified and deterministically validated question. A categorical automatic-release evidence path avoids invented legacy quality scores. Test-origin drafts cannot be released or scored. Practice is one question per session; the next recommendation is chosen after completion. No classroom content is repurposed into another user's private practice.

Phase 16 records first eligible submitted responses once per student/version, excludes skips, expired attempts, repeated exposures, unreleased results and quarantined/confirmed-defective versions, and recomputes topic profiles from retained evidence. The candidate policy exposes its priors, decay, evidence minimum, thresholds, coverage and algorithm version. Difficulty moves by at most one level per eligible observation. Timing is diagnostic only. Unseen private candidates are filtered through all current gates; no eligible bank means no safe practice item, not an unverified substitute.

Changes: additive SQL migrations and restricted functions/grants; backend attempt and adaptive modules; React attempt/result and learning pages; navigation; API/SQL/policy/UI/browser tests; workflow and completion documents. No new paid service, inference, model download or runtime dependency. Use synthetic eligible fixtures for positive tests, clearly separate from AI-quality evaluation. Preserve prior data and PPT claims. Native PostgreSQL concurrency validation remains separate. Stop after both phases are verified; feedback submission/review is Phase 17.
