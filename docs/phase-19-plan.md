# Phase 19 — evaluation harness

Authorized 13 October 2026. R28: matched A/B/C/D pipeline conditions, configurable model pairs, independent review exports and separate adaptive replay. This phase builds measurement tools; it does not establish AI reliability or learning gains.

- Isolated local evaluation package: locked dataset/config hashes, document-separated development/test splits, fixed retrieval snapshots, seeds, prompt/code provenance, append-only candidate records and explicit failed-slot denominators.
- A topic-only baseline; B frozen RAG context; C the exact B candidate plus verifier; D the exact C candidate plus bounded mathematical validation. This paired filtering experiment does not regenerate failed candidates. Model pairs remain separate comparison groups.
- Default deterministic synthetic smoke mode without model execution. Optional explicitly enabled local Ollama runner retains existing tiny-model, memory and token-budget safeguards. Unsupported model pairs fail closed; actual hardware/model quality validation remains pending.
- Blind human review packs, ratings validation, adjudication, raw/retained quality, coverage, retention, errors, duplicate indicators, latency and source-document bootstrap intervals. Missing ratings and unmeasured metrics remain To be evaluated.
- Teacher Evaluation lab runs isolated synthetic smoke checks, stores owned evaluation records and downloads evidence. No evaluation candidate can enter the question bank, approval, publication or scoring flow.
- Separate consent-confirmed, owner-scoped pseudonymous attempt export for offline adaptive-policy replay. Replay compares policy decisions only and cannot infer counterfactual responses or learning improvement.
- No downloads, paid/cloud services, real inference, real learner recruitment or fabricated results. Verify the harness using synthetic/adversarial fixtures, permissions, denominator checks and responsive browser workflows.
